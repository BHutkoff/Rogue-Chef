# Rogue Chef

A Unity game project.

## Open the project

1. Clone this repository, or download and extract its ZIP.
2. Install Unity **2022.3.28f1** through Unity Hub.
3. In Unity Hub, choose **Add project from disk** and select this folder.
4. Open the project and allow Unity to import assets and restore packages.

`Assets`, `Packages`, and `ProjectSettings` contain the shared project. Unity regenerates local folders such as `Library`, `Temp`, `Logs`, and `UserSettings`; these should stay out of Git.

This repository contains the editable Unity project. A playable download requires a separate game build.
